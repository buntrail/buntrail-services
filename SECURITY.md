# Security

Only the latest published 0.1.x release is considered for security fixes.
No response-time or long-term-support guarantee is made during development.

Report suspected vulnerabilities privately to bungamungil@icloud.com. Include
versions, affected platforms, impact and a minimal reproduction with secrets
removed. Do not open a public issue until coordinated disclosure is agreed.
Maintainers will investigate, coordinate a fix and agree on disclosure timing.
