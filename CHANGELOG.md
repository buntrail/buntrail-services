# Changelog

## 0.4.0 — Git sidebar

Add scoped paged history, first-parent binary-aware summaries and sanitized repository context; include untracked paths in repository snapshots. Preserve guarded mutations and exact bytes. Push the captured checked-out commit to the explicit upstream branch even when local/upstream names differ.

## 0.3.0

File-sidebar operations and compatible shared core contracts. C ABI remains version 1.

## 0.2.0 — Git Repository

Browse refs and filtered history, inspect immutable first-parent diffs, and execute guarded local branch actions with durable merge continuation and owned abort authority.

## 0.1.1

Keep terminal restoration state in memory, preserve catalog documents and verified ownership, and retain safe same-run remote reconnect context.
