# Contributing

Read README.md for prerequisites and supported platforms. Open an issue at
https://github.com/buntrail/buntrail-services/issues with a minimal reproduction, expected
and actual behavior, OS, Rust version and relevant redacted logs. Do not include
credentials, private files or vulnerability details in public issues.

Fork the repository, make a focused branch, and run scripts/check.sh. Add a small
regression for non-trivial behavior changes. Describe the problem, solution,
alternatives and actual verification in your pull request; list unavailable
checks explicitly. Keep commits clear and pull requests small. Maintainers
review changes before merging. Submit contributions under the MIT license.
See CODE_OF_CONDUCT.md and SECURITY.md. Contact: bungamungil@icloud.com.
